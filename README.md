   # Ядро интернет-магазина

   В рамках данного задания реализованы основные сущности для e-commerce проекта:
   - Создан класс `Product` (Товар) с атрибутами: название, описание, цена, количество.
   - Создан класс `Category` (Категория) со списком товаров.
   - Добавлены атрибуты класса для автоматического подсчета общего количества категорий и товаров.
   - Написаны тесты с использованием `pytest` (покрытие кода > 75%).
